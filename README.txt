TeamoTrack Website — SEO-Enhanced Package

This package preserves the existing website assets and pages while improving on-page SEO and crawler discovery.

Main public pages:
- index.html
- features.html
- pricing.html
- contact.html
- privacy-policy.html
- terms-and-conditions.html
- refund-policy.html

Technical SEO:
- robots.txt
- sitemap.xml
- page-specific metadata, canonical URLs, social metadata
- homepage JSON-LD structured data
- backup pages marked noindex

Deployment:
1. Extract this ZIP.
2. Upload the contents of the `teamotrack-website` folder to the GitHub Pages publishing root, preserving folders and files.
3. Keep `assets/` and `.well-known/` in their existing locations.
4. Test robots.txt and sitemap.xml on the live domain.
5. Submit the sitemap in Google Search Console.

Read SEO-DEPLOYMENT-CHECKLIST.txt before publishing. SEO improvements cannot guarantee rankings or indexing. Verify business claims and legal policy details before going live.
